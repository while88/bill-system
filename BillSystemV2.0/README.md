这是在账单管理系统V1.0的基础上推出的控制台版的V2.0版本，采用Controller Service Repoository的标准分层架构，解决了V1.0版本中内容职责极度耦合，维护极其困难的状况，并且自定义异常体系，对用户使用过程中可能出现的错误进行封装自定义，避免直接使用java底层Exception导致范围过大不好定位的问题，并对每一处都进行了try-catch处理防止系统崩溃，使用ObjectOutputStream使得此程序半脱离控制台，每次退出系统，在此次项目运行时的账单变化会同步写入本地文件进行持久化保存，在每次启动项目时，自动通过ObjectInputStream读取本地文件中的账单，并写入账单容器，并且通过自定义返回类BigDecimalBox解决了一个方法不能返回两个值的问题，舍弃了1.0版本中可变参数不可控，可读性差的问题，实现了高内聚低耦合的工程思想，适合想了解分层底层原理以及划分职责归属的学者，但此版本并非分层的最终形态，并且考虑到此系统的复杂度以及数据量不大，并未对其加入后台线程架构，在下一个版本我会引入前端页面，使用maven项目结构搭建结构，采用Springboot web使此系统彻底脱离控制台，在web端以可视化界面运行，并且采用DIP思想，引入IOC DI，实现分层的最终形态，并且加入AOP JWT令牌 Filter Interceptor等一系列javaweb内容，使之变成一个真正可以被使用的账单管理系统，或许这一天很快会到来，V3.0-------
